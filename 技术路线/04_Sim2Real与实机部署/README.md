# 04 Sim2Real与实机部署

本路线是算法进入真实足式机器人所需的独立工程专题。

## 内容范围

- 系统辨识、动力学参数、执行器和接触参数
- 域随机化、残差建模、延迟和控制频率
- 模型导出、观测归一化、动作缩放和硬件接口
- 实机安全状态机、保护策略和故障回退
- 日志、回放、指标、回归测试和实验记录

## 阅读重点

不只记录“是否上真机”，还要记录传感器、算力、策略频率、低层控制器、迁移方法和实验边界。
