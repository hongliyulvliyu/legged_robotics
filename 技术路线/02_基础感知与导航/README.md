# 02 基础感知与导航

本路线负责足式机器人在运动控制之外所依赖的基础感知和导航能力。

## 内容范围

- IMU、关节、足端接触和视觉/激光传感器
- 浮基状态估计、速度估计和传感器融合
- 地形、高度图、深度和障碍物表示
- 定位、建图、局部规划和目标导航
- 感知频率、延迟、遮挡和 OOD 场景处理

## 阅读重点

区分“感知结果直接进入控制器”“感知只用于导航策略”和“感知仅用于训练教师”的不同闭环，记录部署时可用的传感器与频率。
