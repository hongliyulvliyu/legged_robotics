# 08 数据平台

本专题用于整理足式机器人相关数据来源、数据格式、日志系统、数据集和训练数据流水线。它服务于训练、评测、复现和实机问题定位。

## 平台范围

| 类型 | 关注点 |
| --- | --- |
| 真实机器人日志 | 关节、IMU、足端接触、力矩、电流、速度、控制命令和安全状态 |
| 仿真 rollout 数据 | 观测、动作、奖励、终止、特权信息、随机化参数和环境状态 |
| 视觉与导航数据 | RGB、深度、LiDAR、地图、目标点、轨迹和障碍物标注 |
| 运动数据与技能数据 | MoCap、参考轨迹、运动先验、技能 token 和重定向结果 |
| 通用数据格式 | rosbag、MCAP、LeRobot、HDF5、Parquet、NumPy 和自定义二进制格式 |

## 使用边界

- 数据平台不直接替代论文阅读或项目复现，只记录数据如何产生、保存、转换和使用。
- 用于 Locomotion 训练的数据应回链到 [03 Locomotion](../03_Locomotion/README.md)。
- 用于 Sim2Real 或故障定位的数据应回链到 [04 Sim2Real与实机部署](../04_Sim2Real与实机部署/README.md)。
- 用于 VLA 或世界模型的数据应说明动作接口和机器人本体差异。
