# 项目（工程主表）

本目录是本知识库的**工程内容索引与独立笔记存放处**：登记已收录的外部开源工程、是否有独立笔记、内容若分散时分别落在哪些文档，以及主技术路线。各工程的详细算法与框架深挖写在本目录下的独立 md 中；技术路线 README 只做综述并链到此处，不复制正文。

项目不按 GitHub 热度收集，而是按其在研发链中的工程位置归类。

## 职责划分

| 文档 | 回答的问题 |
| --- | --- |
| [技术路线/README.md](../技术路线/README.md) | 本知识库的技术路线总框架与归档规则 |
| 各技术路线 README | 该路线的综述，并链到本工程内具体笔记 |
| 本文件（工程主表） | 收录了哪些外部工程、有没有独立笔记、散落在哪 |
| 本目录下各工程独立笔记 | 该工程自身的系统框架与专题深挖正文 |

## 工程分类

| 类别 | 典型内容 |
| --- | --- |
| 训练与强化学习 | 环境、观测、动作、奖励、PPO、课程和策略导出 |
| 经典控制与状态估计 | 动力学、MPC、WBC、QP、接触估计和滤波 |
| 感知与复杂地形 | 高度图、深度、LiDAR、跑酷和野外 Locomotion |

| VLA与具身任务 | 任务理解、技能调用、导航和跨本体动作接口 |
| 世界模型与预测控制 | 预测、想象训练、规划和模型式控制 |

## 项目记录字段

新增工程时至少填写：

- 项目名称和原始链接
- GitHub、项目页和论文链接
- 机器人平台与机器人类型
- 技术路线和工程位置
- **独立笔记路径**（无则写「暂无」；有则放在本目录，如 `Odin_Nav_Stack2.md`）
- **其他文档位置**（路线 README 挂载、交叉引用等）
- 可复现边界：完整训练、部分训练、仅推理、仅项目页或未开放
- 是否可直接用于足式机器人
- 与本工程其他项目的依赖关系

## 维护说明

- 新增开源工程：先在本主表登记一行，再决定是否在本目录建立独立笔记；技术路线 README 只摘要并链接，不放完整正文副本。
- 同一工程只设一个主归属路线；其他路线用链接引用，避免多份不一致正文。
- 原工程批量迁移尚未完成；上表为当前已有独立笔记的登记，后续按需追加行。
