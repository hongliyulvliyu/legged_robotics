## 内容归档规则

- 论文：进入 `论文/`，并在初步阅读记录中注明主路线。
- 项目：进入 `项目/`（工程主表 + 各工程独立 md 正文）；技术路线 README 只做综述并链接到 `项目/` 下具体笔记，不保留完整正文副本。
- 交叉方向：只设一个主归属，其他路线通过链接引用，避免同一条目出现多份不一致描述。
- 通用 VLA 或世界模型：只有在能够说明其输入、输出或训练方式如何连接机器人执行时，才进入本工程的相关路线。
- 仿真平台和数据平台：作为横向支撑专题维护使用技巧、配置经验、数据格式和工具链，不替代算法路线归档。
