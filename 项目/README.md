# 项目

本目录维护足式机器人相关的开源工程、项目页和复现入口。项目不按 GitHub 热度收集，而是按其在研发链中的工程位置归类。

## 工程分类

| 类别 | 典型内容 |
| --- | --- |
| 训练与强化学习 | 环境、观测、动作、奖励、PPO、课程和策略导出 |
| 经典控制与状态估计 | 动力学、MPC、WBC、QP、接触估计和滤波 |
| 感知与复杂地形 | 高度图、深度、LiDAR、跑酷和野外 Locomotion |
| Sim2Real与部署 | 系统辨识、执行器、延迟、硬件接口和安全状态机 |
| VLA与具身任务 | 任务理解、技能调用、导航和跨本体动作接口 |
| 世界模型与预测控制 | 预测、想象训练、规划和模型式控制 |

## 项目记录字段

- 项目名称和原始链接
- GitHub、项目页和论文链接
- 机器人平台与机器人类型
- 技术路线和工程位置
- 可复现边界：完整训练、部分训练、仅推理、仅项目页或未开放
- 是否可直接用于足式机器人
- 与本工程其他项目的依赖关系
